# UX Strategy

## Objetivo
Evitar diseñar una web solo desde criterios visuales.

## Analizar

### Usuario
- quién es
- qué necesita
- qué sabe
- qué teme
- qué intenta lograr

### Negocio
- objetivo principal
- conversión
- diferenciación
- confianza
- retención

### Problema
Escribir una definición concreta del problema.

### Arquitectura
Definir:
- páginas
- secciones
- navegación
- jerarquía
- CTA
- contenido necesario

### User Journey
Para cada etapa:
1. Qué ve.
2. Qué entiende.
3. Qué siente.
4. Qué hace.

## Regla
Cada decisión visual importante debe poder vincularse con una necesidad del usuario o del negocio.

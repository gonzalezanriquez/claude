# Premium Web Design

## Objetivo
Crear interfaces con identidad, jerarquía y sofisticación visual.

## Principios
- Diseñar sistemas, no pantallas aisladas.
- Usar una grilla consistente.
- Crear una escala tipográfica clara.
- Controlar densidad y espacio negativo.
- Reducir elementos innecesarios.
- Diseñar responsive desde el comienzo.
- Priorizar legibilidad.

## Hero
Debe responder rápidamente:
- qué es
- para quién
- por qué importa

Puede tener impacto visual, pero no debe sacrificar claridad.

## Componentes
Evitar componentes genéricos cuando una composición editorial sea mejor.

## Responsive
Revisar como mínimo:
- 1440px
- 1280px
- 1024px
- 768px
- 430px
- 390px

## Checklist
- Jerarquía visible
- Contraste correcto
- CTA claro
- Ritmo entre secciones
- Mobile sin pérdida de sentido
- Navegación comprensible
- Estados hover/focus
- Sin overflow accidental

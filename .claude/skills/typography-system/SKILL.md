# Typography System

## Objetivo
Usar la tipografía como parte central de la dirección de arte y no como una decisión decorativa final.

## Definir
- familia principal y secundaria si corresponde
- roles tipográficos
- escala responsive
- pesos
- interlineado
- tracking
- ancho de lectura
- contraste entre display y body

## Reglas
- Priorizar legibilidad y jerarquía.
- Evitar demasiados tamaños sin sistema.
- Evitar mezclar fuentes sin una función clara.
- Diseñar desktop y mobile como escalas relacionadas, no como simples reducciones.
- Mantener longitudes de línea razonables.

## Entregable
Documentar tokens o variables para display, H1-H6, body, small, labels, navegación y CTA.

## Test de calidad
Preguntar si el sitio conservaría identidad aun quitando imágenes y efectos. Si no, fortalecer el sistema tipográfico y compositivo.

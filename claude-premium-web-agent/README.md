# Claude Premium Web Agent

Paquete inicial para usar con Claude Code y proyectos web premium.

## Qué incluye

- `CLAUDE.md`
- 5 skills:
  - creative-direction
  - premium-web-design
  - ux-strategy
  - threejs-experience
  - gsap-animation
- perfil profesional editable
- prompts iniciales
- ejemplo de flujo de trabajo

## Instalación en un repositorio

Copiá al raíz de tu proyecto:

```text
CLAUDE.md
.claude/
profile/
prompts/
examples/
```

## Claude Code web

1. Crear o abrir un repositorio de GitHub.
2. Subir estas carpetas al repositorio.
3. Abrir el repositorio desde Claude Code.
4. Pedir:

```text
Leé CLAUDE.md, profile/PROFILE.md y las skills disponibles.
No programes todavía.
Confirmame qué rol vas a asumir y qué skills usarías para un proyecto web premium.
```

## Primer proyecto

Después usar `prompts/01-primer-proyecto.md`.

## Personalización

Editar primero:

`profile/PROFILE.md`

No inventar datos. Pegar allí la información profesional que realmente quieras usar como contexto.

## Consejo

No le pidas directamente:

"haceme una web moderna"

Usá este flujo:

Estrategia -> UX -> Concepto -> Dirección de arte -> Movimiento -> 3D -> Frontend -> QA
